# Руководство пользователя

## Аккаунт и проекты

На странице входа выберите «Создать аккаунт». Логин содержит 3-64 буквы, цифры, точки, дефисы или подчёркивания; внешние пробелы удаляются, регистр не учитывается. Пароль содержит 12-128 символов. Если аккаунт создавался с почтой, введите прежний адрес как логин

При первом чтении списка проектов нового аккаунта создаётся «Мои материалы». Каждый проект объединяет свои файлы и несколько чатов. Материалы других проектов не участвуют в ответе

Карточка текущего проекта открывает окно выбора, поиск по названию и «Новый проект». Поиск фильтрует названия в браузере, а не содержимое файлов. Значки справа позволяют переименовать и удалить проект

Выбор проекта/чата не сохраняется отдельной настройкой: после reload выбираются первый проект и наиболее недавно обновлённый чат в нём. Остальная сохранённая переписка доступна через список чатов

## Материалы и прогресс

Нажмите «Добавить материалы» или перетащите файлы. Можно выбрать несколько: браузер отправляет их по одному. GUI принимает `.txt`, `.md`, `.pdf` до 100 MiB на файл. TXT/MD нужны в UTF-8, PDF - с извлекаемым текстом. API дополнительно принимает `.markdown`

| Состояние | Значение |
| --- | --- |
| В очереди | Файл сохранён, обработка ещё не началась |
| Подготовка текста | Извлечение и разбиение, число фрагментов ещё неизвестно |
| Индексируется, N% | Пакеты embeddings записываются в индекс |
| Завершаю индексирование | Пакеты записаны, документ ещё не опубликован |
| Готов | Документ участвует в поиске |
| Ошибка | Показана причина и кнопка «Повторить» |
| Удаляется | Документ исключён из поиска, идёт очистка |

Процент считается по записанным фрагментам, а не по времени или страницам. До ready максимум 99%, после публикации 100%. Повтор начинается заново и может сбросить процент. Список автоматически обновляется, пока есть queued/indexing/deleting материалы; отдельной кнопки перезагрузки материалов нет

Одинаковый файл в том же проекте/profile возвращает существующую запись. В другом проекте загрузка независима. Готовый файл можно принудительно переиндексировать через API с `rebuild: true`; отдельной кнопки rebuild в GUI нет

## Чаты и вопросы

Нажмите «Новый чат» и введите вопрос. До отправки это локальный черновик. При отправке создаётся серверный чат, первое сообщение задаёт название без отдельного LLM-вызова. Длинное название сокращается. Меню «…» у чата позволяет переименовать и удалить его

Enter отправляет вопрос, Shift+Enter добавляет строку. Предел - 4000 символов. История хранится на сервере; в модель передаются последние завершённые сообщения в пределах бюджета

Примеры:

- «Что такое градиентный спуск?» - конкретный поиск
- «Сравни стеки и очереди» - несколько поисковых формулировок
- «Перечисли структуры данных из материалов проекта» - обзор разных разделов
- «Какие ещё есть?» - дополнения с учётом недавней истории

Режим выбирается автоматически. Обзор может занимать дольше: модель извлекает пункты, проверяет смысл и синонимы. Пометка сообщает охват; полного перечисления всего содержимого книг сервис не гарантирует

## Фоновые ответы и остановка

Рядом с чатом видно «В очереди» или «Готовлю ответ…». Можно переключиться на другой чат/проект и отправить следующий вопрос. Принятый запрос продолжается после reload, закрытия вкладки и выхода из аккаунта, пока работает сервер

Очередь общая для всех аккаунтов, один ответ выполняется за раз. В одном чате допустим один queued/pending запрос. Индексация работает отдельным worker и может идти одновременно

Откройте нужный чат и нажмите «Остановить». Если ответ уже сохранён, он останется в истории; иначе под вопросом появится причина. Переключение экранов само по себе не является остановкой

Время рядом с RAGent включает поиск и внутренние вызовы моделей, исключает очередь, доставку по сети и финальную запись ответа. Для старых сообщений без измерения подпись отсутствует

## Источники и формулы

Карточка источника содержит `[Sx]`, имя файла, страницы PDF и отрывок. По нажатию «Открыть фрагмент» по умолчанию выбран **текстовый фрагмент**. Для PDF соседняя вкладка **«Оригинал PDF»** показывает страницу цитаты, позволяет листать и открыть файл отдельно

Сообщения и текстовые источники поддерживают Markdown/LaTeX: `$...$`, `$$...$$`, `\(...\)`, `\[...\]` и math-блоки. Это отображение TeX, который уже есть в тексте; формулы из изображений и PDF-вёрстки автоматически в LaTeX не превращаются

Если полный chunk недоступен, показывается сохранённый отрывок цитаты. После удаления файла его оригинал недоступен. При ошибке оригинала доступны повтор загрузки и переход к тексту. Встроенный PDF viewer зависит от браузера

## Общие ответы и ошибки

На распознаваемые короткие приветствия и вопросы о возможностях помощник отвечает без поиска. Для содержательного вопроса сначала проверяются материалы. При отсутствии подходящих свидетельств допускается ответ из знаний модели с явной пометкой и без карточек источников

Ошибки Ollama, таймаут и невалидные ссылки не маскируются общим ответом. Под неудавшимся вопросом сохраняется причина. После ошибки отправки UI может предложить «Повторить запрос» с прежним UUID. Этот временный элемент не сохраняется после reload; причина failed turn остаётся в истории, новый вопрос можно отправить обычным способом

Обрезанный ответ генерируется заново один раз с увеличенным лимитом. Если повтор не помог, частичный JSON не публикуется. Уточните или разделите вопрос; диагностика описана в [runbook](runbook.md#устранение-проблем)

## Удаление, тема и выход

| Действие | Последствия |
| --- | --- |
| Удалить файл | Исключить из поиска, очистить файл/chunks/vectors; история и цитаты остаются |
| Удалить чат | Удалить его переписку и запросы, отменить работу; файлы проекта остаются |
| Удалить проект | Удалить переписку всех его чатов и поставить файлы на очистку |

Удаление подтверждается. Корзины и восстановления в GUI нет. После удаления последнего проекта создайте новый

Переключатель темы доступен на входе и в верхней панели: светлая, тёмная или системная. Явный выбор сохраняется в `localStorage`; системная тема отслеживает ОС, тема независима от аккаунта

Выход очищает JWT вкладки. После истечения токена нужно войти заново, файлы и история остаются. Сброса пароля по почте, смены логина/пароля и личного кабинета нет
