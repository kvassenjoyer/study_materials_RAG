# Градиентный спуск

Градиентный спуск — итерационный метод минимизации дифференцируемой функции.
На каждом шаге параметры меняются в направлении, противоположном градиенту:

`w_next = w_current - learning_rate * gradient(loss, w_current)`.

Градиент показывает направление наиболее быстрого локального роста функции.
Противоположное направление используется для её уменьшения при подходящем размере шага.
Скорость обучения (`learning_rate`) задаёт величину шага. Слишком большой шаг может
привести к колебаниям или расходимости; слишком маленький замедляет обучение.

## Пример для одной переменной

Пусть `loss(w) = w²`, начальное значение `w = 4`, а скорость обучения равна `0.1`.
Производная равна `2w`, поэтому первый шаг даёт `w_next = 4 - 0.1 * 8 = 3.2`.
Значение функции уменьшается с `16` до `10.24`.

## Разновидности

Полный градиентный спуск вычисляет градиент по всей обучающей выборке.
Стохастический градиентный спуск использует отдельный пример, а метод мини-батчей —
небольшую группу примеров. Мини-батчи позволяют оценивать градиент дешевле, чем по
всей выборке, и использовать векторизованные вычисления.

Этот демонстрационный материал создан для проверки сервиса и не заменяет учебник.
